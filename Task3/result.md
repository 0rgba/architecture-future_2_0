## Технический радар

| Квадрант                   | Текущие технологии      | Статус | Предлагаемые изменения                                                                                                            |
|----------------------------|-------------------------|--------|-----------------------------------------------------------------------------------------------------------------------------------|
| **Языки программирования** | Python, Golang, Java    | Adopt  | Рассмотреть, возможно ли в дополнение к Go для сервисов, требующих высокую произвоительность, оставить один язык из Python и Java |
| **Интеграция**             | Apache Camel            | Hold   | Apache Kafka                                                                                                                      |

## Обоснование роадмепа

Ключевые моменты в новой архитектуре - это **Data Mesh** и **Kafka**, поэтому переход предлагается начать с них, для поиска оптимальных способов внедрения. Когда база будет выстроена, можно будет переносить организовывать мигнацию и строить процессы на новой схеме
